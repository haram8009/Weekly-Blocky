# 회고 탭 정량 차트 설계

## 배경

회고 탭은 `이번 주 요약`, `잘한 점`, `아쉬운 점`처럼 사용자가 직접 적는 서술형 회고보다 실제 시간 사용 수치를 먼저 보여줘야 한다. 사용자는 한 주 동안 어떤 영역이 어느 요일에 몰렸는지, 특정 날짜의 시간 점유율이 어떻게 구성됐는지, 주간 총합이 어떤 비율인지 바로 확인할 수 있어야 한다.

## 목표

- 회고 탭을 정량 분석 중심 화면으로 재설계한다.
- 카테고리 색상 그룹 기준으로 주간 패턴과 일별 점유율을 보여준다.
- 정확한 시간, 비율, 요일별 흐름을 함께 제공한다.
- 기존 회고 메모 입력 UI는 제거한다.

## 화면 구조

회고 탭은 다음 순서로 구성한다.

1. 주 선택
2. 핵심 수치 카드
3. 주간 색상 그룹 비율 선 그래프
4. 요일 선택 탭
5. 선택 요일 도넛 차트
6. 주간 총합 표

## 핵심 수치 카드

핵심 수치 카드는 차트에 넣지 않는 전체 상태를 빠르게 보여준다.

- 총 기록 시간
- 미기록 시간
- 기록 완성률
- 낭비한 시간

미기록 시간은 차트 데이터에 섞지 않는다. 차트는 기록된 시간의 구성과 흐름을 보여주는 데 집중한다.

## 주간 색상 그룹 비율 선 그래프

주간 패턴은 카테고리 색상 그룹별 선 그래프로 표시한다.

- X축은 월요일부터 일요일까지의 요일이다.
- Y축은 해당 요일의 기록된 시간 안에서 색상 그룹이 차지한 비율이다.
- 표시 대상은 상위 6개 색상 그룹과 `기타`다.
- 상위 그룹은 주간 총 기록 시간이 큰 순서로 정한다.
- `기타`는 상위 6개에 포함되지 않은 색상 그룹의 합산값이다.
- 기록이 없는 요일은 모든 그룹의 비율을 0으로 처리한다.

선 그래프는 절대 시간이 아니라 점유율 흐름을 보여준다. 실제 시간 수치는 일별 도넛 차트와 주간 총합 표에서 확인한다.

## 일별 도넛 차트

요일 탭을 선택하면 선택한 요일의 색상 그룹 점유율을 도넛 차트로 보여준다.

- 도넛 차트는 선택 요일의 기록된 시간만 기준으로 한다.
- 미기록 시간은 도넛에 포함하지 않는다.
- 도넛 옆 또는 아래에 색상 그룹명, 시간, 비율 목록을 함께 표시한다.
- 선택한 요일에 기록이 없으면 빈 상태를 표시한다.

모바일 도넛 차트 구현을 위해 `react-native-svg`를 추가한다. 웹도 같은 domain 계산 결과를 사용해 SVG 기반 차트를 구현한다.

## 색상 그룹 라벨

집계 기준은 카테고리 이름이나 이모지가 아니라 카테고리 색상이다.

- 같은 색상을 쓰는 카테고리는 하나의 그룹으로 합산한다.
- 그룹 라벨은 `대표 카테고리 외 N개` 형식을 사용한다.
- 대표 카테고리는 해당 색상 그룹 안에서 주간 기록 시간이 가장 큰 카테고리다.
- 포함 카테고리가 하나뿐이면 해당 카테고리 이름만 표시한다.
- 상세 목록에는 포함 카테고리 이름을 표시한다.

## 주간 총합 표

주간 총합 표는 차트 아래에서 정확한 수치를 정리한다.

- 색상 그룹 라벨
- 포함 카테고리
- 주간 총 시간
- 주간 기록 시간 대비 비율
- 가장 높은 요일

## 제외 범위

- 자동 문장 인사이트
- AI 회고
- 목표 대비 분석
- 회고 메모 작성 UI 유지
- 카테고리 이름/이모지 기준 차트 전환

위 항목은 MVP 이후 후속 범위로 다룬다.

## 구현 메모

- `packages/domain`에 회고 차트용 파생 데이터 생성 함수와 타입을 추가한다.
- 기존 서버 스키마와 `WeekReview` 저장 모델은 변경하지 않는다.
- 기존 `createWeeklyStats`는 가능한 한 유지하고, 차트 전용 계산 함수를 별도로 추가한다.
- 모바일과 웹은 같은 계산 결과를 사용해 플랫폼별 UI만 다르게 렌더링한다.
