# MVP 화면설계

## 1. 문서 목적

이 문서는 MVP에서 필요한 화면과 각 화면의 구성 요소를 정의한다. 실제 디자인 시안 이전 단계의 텍스트 기반 화면 설계서다.

## 2. 화면 구조

| 화면 | 플랫폼 | 목적 | 우선순위 |
|---|---|---|---|
| 온보딩/로그인 | 모바일/웹 | 계정 생성과 로그인 | P0 |
| 이번 주 | 모바일/웹 | 10분 블록 기록과 주간 현황 확인 | P0 |
| 기록 편집 | 모바일/웹 | 기록 추가, 수정, 삭제 | P0 |
| 오늘 상세 | 모바일 | 하루 기록, 사진, 합계 확인 | P1 |
| 사진 권한/매칭 | 모바일 | 사진첩 권한과 시간대 사진 표시 | P1 |
| 카테고리 설정 | 모바일/웹 | 카테고리 관리 | P1 |
| 주간 회고 | 모바일/웹 | 주간 합계와 회고 작성 | P1 |
| 템플릿 관리 | 모바일 | 반복 루틴 저장과 적용 | P2 |
| 설정 | 모바일/웹 | 표시 시간대, 저장 상태, CSV, 사진 권한 | P1 |

## 3. 플랫폼별 화면 원칙

### 모바일 앱

- 기록 입력의 1차 화면이다.
- 터치 드래그, 탭 선택, 시작/종료 시간 직접 입력을 모두 고려한다.
- 사진첩 권한 요청과 사진 매칭은 모바일 앱에서만 제공한다.
- 주간 전체 그리드가 작아질 수 있으므로 오늘 중심 입력을 보완한다.

### 데스크톱 웹

- 열람과 회고의 보조 화면이다.
- 넓은 화면에서 주간 패턴과 합계를 보기 좋게 제공한다.
- 모바일 사진첩을 직접 읽지 않는다.
- 모바일에서 동기화된 썸네일이 있을 때만 사진을 표시한다.

## 4. 전역 내비게이션

### 모바일

하단 탭을 사용한다.

```text
주간 | 오늘 | 회고 | 설정
```

카테고리와 템플릿은 설정 또는 보조 메뉴에서 접근한다.

### 데스크톱 웹

상단 또는 좌측 내비게이션을 사용한다.

```text
이번 주 | 회고 | 카테고리 | 내보내기 | 설정
```

## 5. 화면 1: 온보딩/로그인

### 목적

모바일 앱과 데스크톱 웹에서 같은 데이터를 보기 위한 계정 흐름을 제공한다.

### 구성

```text
[로고/제품명]
- 시간가계부 또는 최종 제품명

[로그인]
- 이메일/비밀번호 로그인
- 소셜 로그인은 후속

[설명]
- 모바일에서 기록하고 데스크톱에서 볼 수 있음
- 사진 원본은 자동 업로드하지 않음

[액션]
- 시작하기
- 로그인
```

### 수용 기준

- 로그인하지 않은 사용자는 개인 데이터를 볼 수 없다.
- 신규 사용자 최초 접속 시 기본 설정을 사용자 데이터로 생성한다.
- 카테고리가 없는 사용자는 예시 카테고리를 참고해 직접 카테고리를 생성한다.
- 사진 권한은 로그인 직후가 아니라 사진 기능 사용 시 요청한다.

## 6. 화면 2: 이번 주

### 목적

사용자가 이번 주의 실제 시간 사용을 기록하고 한눈에 확인하는 핵심 화면이다.

### 주요 구성

```text
[상단 바]
- 이전 주
- 현재 주 범위
- 다음 주
- 오늘
- 저장 상태

[주간 요약]
- 기록 완성률
- 미기록 시간
- 가장 많이 쓴 카테고리
- 낭비한 시간

[10분 블록 그리드]
- 7일 컬럼
- 시간 라벨
- 카테고리 색상 블록
- 드래그 선택 상태
- 사진 썸네일 표시

[카테고리 팔레트]
- 최근 카테고리
- 즐겨찾기 카테고리
- 전체 카테고리
```

### 모바일 레이아웃

- 기본은 오늘 또는 현재 시간대 중심으로 보여준다.
- 주간 전체는 가로 스크롤 또는 축약 보기로 제공한다.
- 카테고리 팔레트는 하단 시트로 제공한다.
- 기록 블록 안의 사진은 작은 썸네일 또는 사진 있음 아이콘으로 표시한다.

### 데스크톱 웹 레이아웃

- 좌측: 시간 라벨
- 중앙: 7일 주간 그리드
- 우측: 주간 요약과 카테고리 합계
- 데스크톱 웹에서는 입력보다 열람, 회고, 내보내기 액션을 우선한다.

### 상태

#### 빈 상태

- 생성된 카테고리가 없으면 예시 카테고리를 먼저 보여준다.
- 그리드는 비어 있는 상태로 표시한다.
- 첫 기록 추가 행동을 방해하지 않는다.

#### 선택 상태

- 선택된 블록은 반투명 강조색으로 표시한다.
- 선택 범위의 시작/종료 시간이 함께 보인다.
- 카테고리 팔레트가 활성화된다.

#### 사진 있음 상태

- 기록 시간대에 매칭된 사진이 있으면 작은 썸네일을 표시한다.
- 표시 공간이 부족하면 사진 개수 배지로 대체한다.
- 사진 권한이 없으면 사진 영역 자체를 강하게 노출하지 않는다.

## 7. 화면 3: 기록 편집

### 목적

기록을 정밀하게 추가, 수정, 삭제한다.

### 구성

```text
[제목]
- 기록 추가 또는 기록 편집

[입력]
- 날짜
- 시작 시간
- 종료 시간
- 카테고리
- 메모

[사진]
- 이 시간대 사진 썸네일
- 사진 숨기기
- 연결 해제

[보조 정보]
- 총 시간
- 겹치는 기록 안내

[액션]
- 저장
- 삭제
- 취소
```

### 규칙

- 시간은 10분 단위 선택지를 기본으로 제공한다.
- 종료 시간은 시작 시간보다 뒤여야 한다.
- 겹치는 기록이 있으면 저장 전 안내한다.
- 사진은 기록 저장 후 시간 범위를 기준으로 다시 매칭한다.

## 8. 화면 4: 오늘 상세

### 목적

모바일에서 특정 하루의 기록, 사진, 합계를 빠르게 확인한다.

### 구성

```text
[상단]
- 날짜
- 이전 날
- 다음 날
- 오늘

[일간 요약]
- 기록 완성률
- 총 기록 시간
- 미기록 시간
- 낭비한 시간

[일간 타임라인]
- 시간대별 색상 블록
- 사진 썸네일

[세션 목록]
- 시작-종료 시간
- 카테고리
- 메모
- 사진 개수
- 편집 버튼

[하루 메모]
- 짧은 일기 또는 메모
```

## 9. 화면 5: 사진 권한/매칭

### 목적

사용자가 사진 기능의 범위와 프라이버시를 이해하고 권한을 제어할 수 있게 한다.

### 진입 경로

- 설정
- 기록 상세의 사진 영역
- 사진 기능 첫 사용 시 안내 화면

### 구성

```text
[권한 상태]
- 허용됨
- 제한됨
- 거부됨

[설명]
- 촬영 시각이 기록 시간 안에 들어오는 사진만 표시
- 사진 원본은 자동 업로드하지 않음
- 데스크톱 웹에는 작은 썸네일만 표시 가능

[액션]
- 사진 접근 허용
- 제한된 사진 선택 변경
- 시스템 설정 열기
- 사진 기능 끄기
```

### 상태

- 권한 없음: 사진 기능 안내와 권한 요청 버튼 표시
- 제한 권한: 선택된 사진만 사용된다는 안내 표시
- 전체 권한: 날짜별 사진 매칭 가능
- 오류: 사진을 읽을 수 없을 때 재시도 제공

## 10. 화면 6: 카테고리 설정

### 목적

사용자가 자신의 삶의 영역에 맞게 기록 카테고리를 관리한다.

### 구성

```text
[카테고리 목록]
- 색상
- 이모지
- 이름
- 주간 목표
- 표시 순서

[카테고리 편집]
- 이름
- 색상
- 이모지
- 주간 목표 시간
- 삭제 또는 보관

[통계 그룹 기준]
- 색상
- 카테고리 이름
- 이모지

[후속 추천 기능]
- 이름 기반 추천 색상
- 이름 기반 추천 이모지
- 추천 다시 받기
- 직접 선택으로 변경
```

### 예시 카테고리

예시 카테고리는 생성 힌트이며, 사용자가 저장해야 실제 카테고리가 된다.

- 수면
- 이동/식사
- 공부/주요 업무
- 자기개발
- 영적시간
- 운동/건강
- 가족/관계
- 집안일/심부름
- 휴식
- 낭비한 시간

### 후속 기능

카테고리 추가 시 사용자가 이름만 입력하면 추천 색상과 추천 이모지를 보여준다. 추천은 보조 기능이므로 사용자가 직접 색상과 이모지를 바꿀 수 있어야 한다.

## 11. 화면 7: 주간 회고

### 목적

사용자가 한 주의 시간 사용을 보고 회고를 남긴다.

### 구성

```text
[주 선택]
- 이전 주
- 현재 주 범위
- 다음 주

[주간 요약]
- 총 기록 시간
- 미기록 시간
- 기록 완성률
- 낭비한 시간
- 사진이 있는 기록 수

[통계 합계]
- 집계 기준 선택: 색상 / 카테고리 이름 / 이모지
- 카테고리 이름
- 색상
- 이모지
- 총 시간
- 비율
- 주간 목표 대비

[회고 질문]
- 이번 주 시간 사용은 중요하게 생각하는 가치와 맞았나?
- 가장 많이 새어 나간 시간은 무엇인가?
- 사진을 보면 떠오르는 이번 주 장면은 무엇인가?
- 다음 주에 줄일 것과 늘릴 것은 무엇인가?

[회고 메모]
- 이번 주 요약
- 잘한 점
- 아쉬운 점
- 다음 주 집중할 것
```

## 12. 화면 8: 템플릿 관리

### 목적

반복되는 하루 루틴을 저장하고 날짜에 적용한다.

### 구성

```text
[템플릿 목록]
- 평일 기본 루틴
- 주말 기본 루틴
- 공부하는 날
- 출근일

[템플릿 편집]
- 템플릿 이름
- 템플릿 엔트리 목록
- 시간
- 카테고리
- 메모

[적용]
- 적용 날짜 선택
- 기존 기록 덮어쓰기 확인
```

### MVP 판단

템플릿은 P2다. 핵심 기록 UX와 서버 저장 흐름이 완성된 뒤 추가한다.

## 13. 화면 9: 설정

### 목적

사용자 환경 설정, 저장 상태, 사진 권한, 데이터 내보내기를 제공한다.

### 구성

```text
[계정]
- 로그인 이메일
- 로그아웃
- 저장 상태

[시간 표시]
- 기본 시작 시간
- 기본 종료 시간
- 00:00-24:00 전체 보기
- 주 시작 요일

[사진]
- 사진 접근 권한 상태
- 사진 기능 켜기/끄기
- 썸네일 동기화 켜기/끄기

[데이터]
- 현재 주 CSV 내보내기
- 전체 기록 CSV 내보내기
- 로컬 사진/썸네일 캐시 초기화
```

## 14. 접근성 기준

- 색상만으로 카테고리를 구분하지 않는다.
- 카테고리 이름 또는 이모지를 함께 제공한다.
- 버튼과 선택 영역은 키보드 포커스를 가져야 한다.
- 색상 대비는 기본 텍스트와 배경에서 충분해야 한다.
- 모바일 터치 타깃은 충분히 크게 잡는다.
- 사진 썸네일에는 기록 시간 또는 대체 텍스트를 제공한다.

## 15. 화면별 완료 기준

| 화면 | MVP 완료 기준 |
|---|---|
| 온보딩/로그인 | 모바일과 웹에서 같은 계정으로 로그인 가능 |
| 이번 주 | 시간 선택, 색상 적용, 주간 이동, 저장 상태 표시 가능 |
| 기록 편집 | 기록 추가/수정/삭제와 사진 표시 가능 |
| 오늘 상세 | 하루 합계, 세션 목록, 사진 개수 확인 가능 |
| 사진 권한/매칭 | 권한 상태 확인과 기록 시간대 사진 표시 가능 |
| 카테고리 설정 | 카테고리 생성/수정/보관 가능 |
| 주간 회고 | 주간 합계와 회고 메모 저장 가능 |
| 설정 | 시간대, 저장 상태, 사진 권한, CSV 관리 가능 |
